대항해시대 II 독립판 1.0.5

수정 및 추가
- 안나 얼굴 오류: 종업원의 나이를 초상화 번호로 읽던 코드를 실제 종업원 초상화 번호로 수정했습니다. 전체 종업원과 이름이 같은 두 안나를 검사했습니다.
- 상인·일반 대화·함대장의 초상화를 화자별로 구분합니다. 초상화 정보가 없는 경우 조안으로 표시하지 않습니다.
- 건물 간판을 나무·건물·인물보다 앞에 표시하고, 화면 경계와 겹침을 보정했습니다. 간판도 눌러 이동/입장할 수 있습니다.
- 함대의 인사와 소문을 누르면 실제 답변 창이 열립니다.
- 실시간 해전: 이동과 조준/포격을 동시에 조작할 수 있습니다. 보유 포탄, 재장전, 포종, 사거리와 지형 충돌을 적용합니다.
- 대장 함선을 표시하고 가까이 접근했을 때 일기토 신청 버튼을 표시합니다. 일기토 동안 해전은 정지하며 결과를 전투에 반영합니다.
- 메뉴를 열면 실시간 해전은 일시정지합니다. 해전 저장/불러오기에 좌표, 탄약, 재장전과 진행 중인 포탄을 보존합니다.
- 메인 화면과 게임 메뉴에 게임 에디터를 추가했습니다. 금화, 동료 능력치/레벨, 아이템을 수정하고 변경 내역 확인 후 적용합니다. 적용 전 내부 백업을 만들며 기존 저장 선택도 지원합니다.
- 항해 기본 시야를 이전보다 약 3~4배 넓은 면적으로 조정했습니다. 항해 화면의 +/−로 4단계 시야를 선택하며 마을 시야와 별도로 기억합니다.
- 해안선과 마을 물가를 곡선으로 연결하고 지면·건물 주변을 정리했습니다. 육지와 바다의 명도/색상 차이를 높였습니다.
- 가로/세로 메뉴 최적화와 기존 저장 호환을 유지합니다.

조작
해전: 왼쪽 방향타로 이동, 오른쪽 조준판을 누르거나 끌어 조준·연속 사격, 포격 버튼으로 현재 조준 방향 사격. PC는 방향키+Space도 지원합니다. 포탄은 실제 보유량에서 소비합니다.
일기토: 적 대장 함선 가까이 이동한 뒤 나타나는 일기토 신청을 누릅니다.
에디터: 메인 화면의 게임 에디터에서 저장 선택, 또는 게임 메뉴에서 열기 → 금화/능력치/아이템 → 변경 확인 → 적용.
