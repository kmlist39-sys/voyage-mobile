# 대항해시대 II 독립판 1.0.2

[Android APK 다운로드](voyage-independent.apk) · [소스 ZIP](voyage-independent-1.0.2-source.zip) · [변경 사항](RELEASE-NOTES.txt) · [검증 기록](VALIDATION.json)

교역소·주점·조선소·보급·저장 메뉴를 가로·세로 화면에 맞게 재배치했습니다. 최종 확인 버튼을 고정하고 긴 내용만 스크롤합니다. 보급과 선박 주문은 가로에서 두 영역으로 나누고, 저장 목록은 화면 방향에 맞춰 1~2열로 표시합니다.

기본 마을 시야는 검증한 휴대폰 크기에서 기존보다 약 3배 넓은 면적을 보여줍니다. 상단 정보·하단 아이콘·방향타 크기를 줄였으며, +/− 버튼으로 4단계 확대율을 선택합니다. 인물 크기와 터치 좌표도 함께 조정했습니다.

156개 자동 규칙 검사 통과. 320×568, 390×844, 568×320, 640×336, 844×390 화면 각각 130항구·889시설·4,302대화·98입력/게임 화면을 자동 검사했습니다. 메뉴 경계·가로 넘침·버튼 접근 검사 오류는 0개입니다.

Android 에뮬레이터에 이 APK를 설치해 기존 저장 불러오기, 마을 확대/축소, 건물까지 이동·입장·대화 후 복귀를 확인했습니다. 전체 대사는 자동 화면 검사이며 모든 대사를 사람이 읽으며 진행한 검증은 아닙니다. 실물 휴대폰은 테스트하지 않았습니다.

Android 8.0 이상, 앱 버전 1.0.2 (6), 패키지 `kr.voyage.independent`. 이전 독립판 위에 업데이트하면 저장을 유지합니다. 원본 DOS 실행 파일이나 에뮬레이터를 실행하지 않으며 네트워크 권한 없이 오프라인으로 작동합니다.
