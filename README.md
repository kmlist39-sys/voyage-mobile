# 대항해시대 II 한국어 모바일판

Android APK 배포 저장소입니다. 원작 엔진을 바탕으로 새 그래픽과 터치 인터페이스를 적용한 비공식 프로젝트입니다.

## 다운로드

**[Android APK 다운로드](https://github.com/kmlist39-sys/voyage-mobile/releases/latest/download/voyage.apk)**

[버전별 다운로드 및 변경 사항](https://github.com/kmlist39-sys/voyage-mobile/releases)

- 버전: 1.5 (versionCode 6)
- Android 7.0 이상
- 파일 크기: 약 29.6 MiB

## 설치와 실행

1. Android 기기에서 위의 APK 다운로드 링크를 엽니다.
2. 내려받은 `voyage.apk`를 열어 설치합니다.
3. 기존 버전이 설치되어 있다면 삭제하지 않고 업데이트 설치합니다. 앱 삭제 시 저장 데이터가 지워질 수 있습니다.
4. 게임에서 **저장한 항해 → 저장 슬롯 → 하단 불러오기**를 누르면 이어서 진행합니다.

## 1.5 변경 사항

- 저장 슬롯 선택과 확인 화면을 분리하여 불러오기 버튼이 화면 밖으로 밀리는 문제를 수정했습니다.
- 날짜를 한글로 표시하고 중복 표시를 제거했습니다.
- 작은 화면의 저장 목록을 한 열로 배치하고, 불러오기·취소 버튼이 항상 보이도록 정리했습니다.
- 저장 및 불러오기 취소 시 기존 저장 파일을 유지합니다.

1~10번 슬롯 저장·불러오기, 취소, 재시작 후 복원과 Android 에뮬레이터 터치 동작을 검증했습니다. 실물 휴대폰 전 기종을 검증한 것은 아닙니다.
