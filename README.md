# 대항해시대 II 독립판 1.0.1

[Android APK 다운로드](https://github.com/kmlist39-sys/voyage-mobile/raw/refs/heads/independent-1.0.1/voyage-independent.apk)

건물 메뉴 아래쪽이 잘리던 문제를 수정했습니다. 가로 화면에서 버튼을 2~3열로 배치하며, 나가기 버튼은 고정됩니다. 긴 목록은 터치 스크롤과 아래 메뉴 보기 버튼으로 끝까지 접근할 수 있습니다.

- Android 8.0 이상, 오프라인 실행
- DOS 게임이나 DOSBox를 실행하지 않는 독립 엔진
- 기존 독립판 위에 업데이트하여 저장 유지
- 154개 규칙 검사 통과
- 휴대폰 화면 크기 5종마다 130항구·889시설·4,302대화·94입력 화면의 자동 검사 통과
- 이 APK를 MuMu에 설치해 기존 런던 저장 복원, 하단 투자 메뉴 선택, 저장 목록 및 표·수량 입력창 스와이프 확인
- 실물 휴대폰 및 여섯 캠페인 전체 수동 플레이는 미검증
