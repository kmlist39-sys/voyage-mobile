대항해시대 II 독립판 1.0.9

- 함대 첫 화면에 현재 기함 이름과 기함 변경 버튼을 추가했습니다.
- 항구에서 함대 → 기함 변경 → 새 배 선택 → 이 배를 기함으로 순서로 변경합니다.
- 조선소의 선박 관리와 함대의 선박 관리에서도 바로 기함으로 지정할 수 있습니다.
- 제독과 기존 선장이 배를 교대하며, 선원과 물자는 각 배에 유지됩니다. 선원이 없는 새 배는 배치 안내를 표시합니다.
- 저장 복원과 출항 후 해전에서도 변경된 배를 기함으로 사용합니다.

검증: 자동 테스트 195/195 통과. 세로 360×640와 가로 844×390에서 기함 선택·확인창·완료창과 현재 기함 표시를 검증했고, 페이지를 다시 열어 자동 저장에서도 새 기함이 유지됨을 확인했습니다. Android MuMu에서 APK 업데이트 후 기존 두 척 함대 저장을 불러와, 실제 터치 입력으로 두 번째 배를 기함으로 변경하고 완료 화면까지 확인했습니다. 물리 휴대폰에서는 검증하지 않았습니다.
