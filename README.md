대항해시대 II 독립판 1.0.6 · 해전 타격감과 일기토

- 긴 방향선을 없애고 원형 조준점으로 변경했습니다. 바다를 누르면 그 위치를 조준하고, 적선을 누르면 추적합니다. 오른쪽 조준판을 끌면서 연속 사격할 수 있습니다.
- 발사 섬광·포연·반동, 공중으로 날아가는 포탄·궤적·그림자, 명중 시 폭발·불꽃·파편·연기·피해 표시, 빗나갈 때 물보라를 추가했습니다.
- 마지막 포격으로 전투가 끝나도 폭발을 보여준 뒤 결과로 넘어갑니다. 그 사이 저장/복원도 검증했습니다.
- 포격·명중·검 휘두르기·검 부딪힘 효과음을 추가했습니다. 소리 설정을 따릅니다.
- 함선은 선수를 돌린 방향으로 이동하며 가속·감속합니다. 선회 중 옆으로 미끄러지는 이동을 수정했고 항적과 선체 흔들림을 추가했습니다.
- 기본 전투 시야는 기존 대비 약 2.4~2.6배 넓은 면적을 보여줍니다. 전장 +/−로 3단계 배율을 바꾸고 설정을 기억합니다.
- 일기토는 갑판/주점 배경에서 전신 인물이 직접 공격·방어·회피합니다. 공격 준비→접근→타격/방어→복귀를 재생한 뒤 기존 승부 계산을 적용합니다.
- 일기토 동작 중 중복 입력을 막고, 최대 20회 교환 뒤 해전으로 정상 복귀하는 것을 확인했습니다.
- 전신 동작은 남녀 공통 전투 에셋을 사용하며, 상단 초상화와 이름은 실제 인물로 표시합니다.
- 1.0.5의 안나·상인 초상화, 간판, 에디터, 함대 인사, 넓은 항해 시야 개선을 포함합니다.
