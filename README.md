대항해시대 II 독립판 1.0.8

- 주점·여관의 항해사에게 인사, 항해 소문, 고용 제안 결과를 실제 대화창으로 표시합니다. 술 대접과 거절 사유도 읽고 닫을 수 있습니다.
- 기도 완료·같은 방문의 반복 기도, 기부 감사와 기부액·잔액을 표시합니다.
- 적 함대가 접근하면 시간이 멈추고 교전 통보와 전투/도주 선택을 표시합니다. 도주 실패 후에도 준비 버튼을 누른 뒤 전투가 시작됩니다.
- 전장의 네 방향 바다 경계로 바깥쪽 이동을 계속하면 자동 이탈합니다. 경계를 표시하고 이탈 결과를 확인한 뒤 항해로 돌아갑니다.
- 교전 통보 중 저장 복원, 중복 응답 방지와 추격 유예를 검증했습니다.
- 1.0.7의 압축 저장과 별도 전투 연습을 포함합니다. 연습 배는 내구력 10,000, 선원 500, 포탄 1,000이며 실제 저장에는 영향을 주지 않습니다.

검증: 자동 테스트 193/193 통과. 가로 844×390·세로 360×640의 실제 웹 UI에서 주점·여관 대화, 기도·기부, 교전 통보·도주 결과와 전투 진입을 확인했습니다. 전장 네 방향 이동 이탈은 게임 엔진 통합 테스트로 검증했습니다. Android MuMu에서 최종 APK 업데이트·기존 저장 불러오기와 교회 기도를 확인했습니다. 물리 휴대폰 검증이나 전체 시나리오 수동 완주를 뜻하지 않습니다.
