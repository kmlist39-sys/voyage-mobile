원본 DOS 게임을 실행하지 않는 독립 JavaScript 게임 엔진과 Android 오프라인 앱입니다.

- 항해 속도/바람/해류/육지 충돌, 물·식량 소비, 날씨·질병, 경험·명성·한글 날짜와 시간.
- 교역/물가/월별 투자/은행, 선원 모집, 물자 MAX·하역·반반 보급, 선장/업무/선원 이동.
- 조선/중고선/수리/개조/함포/선수상, 왕실 지원·문서, 발견물/보물/보고 계약과 기술 습득.
- 해전 이동·포격·백병전·일기토·전술·도주·전리품·나포, 블랙잭과 포커 다이스.
- NPC의 투자·교역·귀항 처리, 국가 경제력/점유율/전략 갱신, 함대 보충과 경쟁자 성장.
- 직접 누르는 독립 메뉴, 표와 수량 입력, 자동 1개 + 수동 5개 저장/복원.
